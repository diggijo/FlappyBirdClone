Flappy Bird Clone 🐦

A small Flappy Bird-style game built with Unity and C#. I'm using this project to improve my code structure and learn how to take a game from start to finish, including gameplay, UI, game states, input, and overall project organisation. I used CodeMonkey's LuaLander tutorial as a guide and adapted the concepts to build my own version.

![Flappy Bird Gameplay](gameplay.gif)

What I'm Practising
- Writing cleaner and more structured C#
- Game state management
- C# events and communication between systems
- Unity's Input System
- Rigidbody2D physics
- UI and scoring
- Animation
- Object pooling
- Scene management
- Structuring a complete game
- Controls
